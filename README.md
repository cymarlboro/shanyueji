# 山月记

自然地理学背诵与间隔复习 Android 应用。

本仓库用于项目维护、问题反馈和版本发布。后续安装包统一通过本仓库的 Releases 提供；当前尚未发布正式安装包。

## 功能方向

- 覆盖选择、填空、判断、名词解释、简答、论述、读图分析及配对题。
- 显示答案后，通过“熟记 / 遗忘”安排后续复习；支持编辑个人答案。
- 用户自行配置兼容的 AI 服务生成问答草稿，确认后加入题库。
- 云端资料默认私有，用户之间互不可见；授权管理员可进行内容审核。云端接入仍在开发和验证中。

## 安装与更新

适配 Android 8.0 及以上。版本发布后，同一签名和应用身份的新版支持覆盖安装，保留本机学习数据。

## 数据与隐私

本公开仓库不存放用户上传资料、个人学习记录、模型 API 密钥、数据库管理员凭据或应用签名私钥。

请勿在公开 Issue 中提交密钥或私人文件。
